# Side Quest icons

These four icons come from the 3dicons V1 color collection by Vijay Verma:

- Lab: https://3dicons.co/icons/56180e-lab?angle=dynamic
- Gym: https://3dicons.co/icons/10c35a-gym?angle=dynamic
- Tools: https://3dicons.co/icons/ff5be0-tools?angle=dynamic
- Link: https://3dicons.co/icons/2d9fa2-link?angle=dynamic

The collection is released under the CC0 1.0 Universal license. The icons use
a site-specific graphite, brushed-silver, and pulse-red material treatment based
on the design tokens in `app/redesign.css`. The final transparent assets are
resized to 500 by 500 pixels and converted to WebP for the site.
